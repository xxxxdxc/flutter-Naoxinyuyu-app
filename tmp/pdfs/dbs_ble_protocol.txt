广播发送模式
- 设备在未连接状态，将会发送可连接广播。

蓝牙配对流程




- App 与设备通过蓝牙 4.2 以上的 LESC 方式进行配对，获得基础安全连接。

- App 检查设备是否存在密钥，如果不存在，则向设备发送 32 字节的 Secret Key 和 4 字节的 Adata，
用于 App 合法性验证与数据的加解密。

- App 检查设备是否信任该 App，如果 App 未与设备建立信任，则需要经过合法性验证。具体方式
为：App 首先通过 ECDH 算法，生成一把私钥与公钥，然后将公钥发送给设备；设备通过相同算法生
成自己的私钥与公钥，将公钥发送给 App；App 和设备通过对方的公钥，计算出共享密钥；App 使
用 HMAC-SHA256 算法，使用共享密钥，对 Secret Key 计算摘要，将摘要发送给设备进行验证；通
过验证后，设备将 App 加入信任列表。
- 如果设备对应用层数据没有加密需求，可以跳过合法性验证流程。

PDU Length：协议数据长度，不包含 opcode 和自身。数据内容可以为空，此时长度为 0。

注：n 为刺激触点对数，有效值为 1~8。


0x00：刺激编程组号，有效值为 1~4，分别代表组 1~4。如配置为 0 则删除所有编程组。

0x01：刺激方式，0 表示恒流刺激，1 表示恒压刺激。

0x02：刺激频率，有效值为 2~250，单位 Hz。

0x03：刺激触点对数，有效值为 1~8，如配置为 0 则删除该编程组。

0x04：刺激触点序号，有效值为 0~16，0 表示 COM 端。两个 u8 分别表示两个触点的序号，顺序无
影响。

0x05：如果刺激方式为恒流刺激则表示刺激电流，有效值为 0~25.5，单位 mA；如果刺激方式为恒
压刺激则表示刺激电压，有效值为 0~10.5，单位 V。

0x06：刺激脉宽：有效值为 20~450，单位 μs。

0x07：极性对称波形之间的时间间隔，常量（默认 60），单位 μs。

0x08：软起动，有效值为 0/1/2/4/8，单位秒。0 表示没有软起动。
0x09：循环刺激间隔，有效值为 0~65535，单位秒。第一个 u16 表示刺激时长，第二个 u16 表示间
歇时长。0 表示关闭此功能。

0x0A：主动放电，0 表示关闭，1 表示开启，默认开启。

0x0B：刺激编程组名，使用 UTF-8 编码存储，超过长度自动截断。

0x0C：刺激程序组，0 表示程序组 1（左），1 表示程序组 2（右）。

Bit 3 — Control Start：控制器开关，1 表示开，0 表示关。

Bit 4 — LFP Sample Start：LFP 感测开关，1 表示开，0 表示关，未连接 App 或连接断开后自动关

0x03：开启存储数据上传，1 表示开，0 表示关，每次连接上 APP 后默认关。

0x04：开启运输(Shipping)模式，1 表示开，0 表示关，上电默认关。

Stop：结束时间，有效值为 0~1440，单位分。

0x08：刺激器开关，1 表示开，0 表示关，上电默认关闭。

0x09：阻抗测量开关，1 表示开，0 表示关。每日 0 时 0 分自动执行一次阻抗测量。
