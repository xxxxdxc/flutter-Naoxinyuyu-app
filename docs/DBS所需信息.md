# DBS 蓝牙连接所需信息

本文档用于向 DBS 硬件/嵌入式同学确认 BLE 对接信息。只有以下信息明确后，App 才能实现：

- 向 DBS 发送压力得分；
- 向 DBS 下发刺激参数；
- 向 DBS 下发紧急停止命令；
- 接收并可视化 DBS 端上传的 LFP 与刺激状态。

## 4. 通用包格式与可靠性

请确认 DBS 协议采用文本格式还是二进制格式。

| 项目 | 待填写 | 说明 |
|---|---|---|
| 协议格式 | 文本 / 二进制 | 文本便于调试，二进制效率更高 |
| 帧头/帧尾 |  | 例如 `START/END` 或 `0xAA55` |
| 数据长度字段 | 有 / 无 | 二进制协议建议包含 |
| 校验方式 | 无 / XOR8 / CRC8 / CRC16 | 建议至少 XOR8 或 CRC16 |
| 是否有包序号 | 是 / 否 | 用于判断丢包 |
| 是否有 ACK | 是 / 否 | 参数下发和急停建议有 ACK |
| 错误码定义 |  | 参数越界、校验失败、设备忙等 |

建议二进制通用格式：

```text
帧头(2B) + 包类型(1B) + 包序号(1B) + 数据长度(2B) + 数据区(NB) + CRC16(2B)
```

建议包类型：

| 包类型 | 方向 | 含义 |
|---|---|---|
| `0x10` | App -> DBS | 压力得分 |
| `0x11` | App -> DBS | 刺激参数 |
| `0x12` | App -> DBS | 刺激开关 |
| `0x7F` | App -> DBS | E-STOP |
| `0x20` | DBS -> App | LFP 波形 |
| `0x21` | DBS -> App | DBS 状态 |
| `0x22` | DBS -> App | 参数反馈 / ACK |
| `0x23` | DBS -> App | 错误信息 |

## 6. App 端最小联调流程

硬件信息齐全后，App 端按以下顺序接入，避免影响现有 HRV 胸环功能。

1. 新增独立 `DbsBleService`，不改现有 HRV 胸环 `BleService`。
2. 实现 DBS 扫描、连接、断开和连接状态显示。
3. 实现 DBS Notify 订阅，先解析 `DBSSTAT` 状态包。
4. 实现 LFP 数据包解析和实时波形显示。
5. 实现刺激参数下发。
6. 实现 E-STOP。
7. 实现压力得分定时/变化触发发送给 DBS。
8. 将 DBS 状态和参数反馈写入历史记录。
