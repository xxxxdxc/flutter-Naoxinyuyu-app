# 离线数据测试功能需求文档

## 一、概述

本文档定义 Flutter 上位机（脑心愈郁 App）中的**离线数据测试功能**的需求规格。

### 1.1 功能定位

- **功能名称**：离线数据测试
- **入口位置**：数据分析页（VisualizerPage）第 3 个标签页 —— "离线测试"
- **使用场景**：用户可在未连接 BLE 硬件时，导入本地 `.mat` 数据文件进行离线分析
- **核心能力**：选取 `.mat` 文件 → 解析 ECG 数据 → 展示波形图 → 计算 HRV 指标

### 1.2 与现有功能的关系

| 现有功能 | 关系说明 |
|---------|---------|
| 实时波形 | 离线测试是实时波形的离线补充，数据来源不同（文件 vs BLE） |
| 分析报告 | 离线测试生成的一次性指标可作为分析报告的输入数据 |
| BLE 连接 | 离线测试不依赖 BLE，蓝牙断开时仍可用 |

## 二、交互流程

```
用户进入"数据"页面
  └→ 切换到"离线测试"标签页
      └→ 点击"选择 .mat 文件"按钮
          └→ 系统文件选择器弹出（过滤 .mat 后缀）
              └→ 用户选取文件（如 send_xzc/live_result/Live_ECG_0505_1652.mat）
                  └→ 页面显示文件名
                      └→ [Step 2] 解析 .mat → 绘制波形 → 计算指标
                          └→ 展示 ECG 波形图
                          └→ 展示 HRV 指标卡片
```

## 四、数据解析

### 4.1 .mat 文件格式

数据来源为 `send_xzc/live_result/` 目录下的 MATLAB `.mat` 文件。

**变量结构**（已验证）：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `raw_data` | double 数组 | ADC 原始采集信号（单极性，约 3.0-4.9） |
| `stm32_filtered_data` | double 数组 | STM32 硬件带通滤波后信号（双极性，约 ±1.0） |

**采集参数**：
- 采样率：500 Hz
- 时长：每文件 10 秒（5000 采样点）
- 滤波范围：0.5-40 Hz 带通

### 4.2 解析方案

- 使用纯 Dart 实现 MATLAB v5 `.mat` 格式解析
- Target：提取 `stm32_filtered_data` 用于波形显示和指标计算
- 后续可用 `raw_data` 对比滤波前后效果

### 4.3 指标计算（Step 2 实现）

从 `stm32_filtered_data` 中计算：

| 指标 | 计算方法 | 单位 |
|------|---------|------|
| 心率 | R 峰检测 → RR 间期 → 60/RR 均值 | BPM |
| SDNN | 全部 RR 间期的标准差 | ms |
| RMSSD | 相邻 RR 间期差值的均方根 | ms |
| R 峰总数 | 检测到的 R 峰数量 | 个 |
| 分析时长 | 数据长度 / 采样率 | s |
