# App 与 DBS 连接功能点及验收标准

> 项目：基于 ECG-LFP 双模态的抑郁症闭环 DBS 调控系统
> 文档对象：上位机 App 与 DBS 植入/刺激端连接、数据收发、参数控制和融合联调
> 当前状态假设：HRV 胸环 → App 已基本跑通；App → DBS 仍处于开发/联调阶段
> 目标：列出 App 与 DBS 连接中需要完成的全部功能点，并给出可执行验收标准。

---

## 1. 功能边界说明

App 与 DBS 的连接模块主要负责以下事情：

1. 扫描、连接、断开和重连 DBS 设备；
2. 订阅 DBS 上行数据，包括设备状态、ACK、错误信息和 LFP 流数据；
3. 通过 Write Characteristic 向 DBS 下发压力分数、刺激参数、运行模式、刺激启停和 E-STOP；
4. 将 HRV 胸环得到的压力分数转发给 DBS，形成 `HRV → App → DBS` 的在线融合链路；
5. 在 App 页面中展示 DBS 连接状态、LFP 波形、刺激状态、参数反馈、压力分数发送状态和错误信息；
6. 将 DBS 状态、刺激参数、融合发送记录和异常事件写入历史记录。

需要强调：App 可以完成参数编辑、BLE 指令下发和状态展示，但最终是否执行刺激必须由 DBS 固件完成参数限幅、阻抗检查、安全互锁和状态确认。App 不应绕过 DBS 固件安全逻辑。

---

## 2. 总体联调链路

```text
HRV 胸环
  ↓ BLE Notify
App 接收 ECG / HRV / STR / pressure_score
  ↓
App 构造 DBS 压力输入包
  ↓ BLE Write
DBS 接收 HRV 压力分数
  ↓
DBS 固件融合 LFP 主状态 + HRV 辅助状态
  ↓
DBS Notify 返回 ACK / 状态 / LFP 流数据
  ↓
App 展示波形、状态、参数、发送结果并归档
```

---

## 3. 开发优先级划分

| 优先级 | 功能模块 | 说明 |
|---|---|---|
| P0 | DBS BLE 基础连接 | 不打通连接，后续全部无法进行 |
| P0 | DBS Write / Notify | 必须能写命令、收 ACK 或状态 |
| P0 | HRV 压力分数发送 DBS | 当前融合阶段核心任务 |
| P0 | E-STOP 急停 | 安全底线，必须优先完成 |
| P1 | DBS 状态解析与显示 | 用于判断 DBS 是否在线、是否运行 |
| P1 | LFP Stream Data 接收与显示 | 用于 CH1 LFP 波形展示 |
| P1 | 刺激参数下发与回读 | 用于控制页和参数同步 |
| P1 | 错误码 / ACK / 超时处理 | 用于联调定位问题 |
| P2 | 历史记录与日志归档 | 用于复盘和比赛展示 |
| P2 | 融合调试页 / 手动测试分数 | 提高联调效率和演示稳定性 |

## 4.6 HRV 压力分数发送给 DBS

这是当前融合阶段最核心功能。

| 编号 | 功能点 | 开发要求 | 验收标准 | 测试证据 |
|---|---|---|---|---|
| DBS-FUSION-001 | 获取 HRV 压力分数 | 从 HRV STR 状态读取 score_raw、score_smoothed、is_stressed、infer_count | App 内部能拿到最新压力分数和状态 | Debug 日志 |
| DBS-FUSION-002 | 判断 HRV 是否可用 | 未校准、校准中、应激诱导中、信号差时不作为正式融合输入 | 页面显示“等待校准完成/信号质量不足”，不误发正式包 | UI 截图 |
| DBS-FUSION-003 | 构造压力分数包 | 将压力分数、状态、序号、时间戳等打包 | 固件能解析出正确 score 和状态 | 固件对照 |
| DBS-FUSION-004 | 定时发送 | 推理状态下按 1 Hz 或约定频率发送 | 连续 5 分钟发送稳定，无明显漏发 | 发送日志 |
| DBS-FUSION-005 | 状态变化触发发送 | 压力分数明显变化时可立即发送一次 | 分数变化后 DBS 端能及时更新 Ep(t) | 对照日志 |
| DBS-FUSION-006 | 接收 DBS ACK | 压力分数包发送后等待 ACK | 页面显示“DBS 已接收”或具体错误 | ACK 截图 |
| DBS-FUSION-007 | 超时处理 | 超过 3–5 秒未收到 ACK，提示发送超时 | App 不崩溃，状态变为“发送失败/超时” | 超时测试 |
| DBS-FUSION-008 | DBS 未连接保护 | DBS 未连接时禁止发送 | 按钮置灰或提示“DBS 未连接” | UI 截图 |
| DBS-FUSION-009 | 手动测试分数 | 提供 0/25/50/75/100 或滑条测试发送 | 无 HRV 数据时也可测试 App → DBS 链路 | 联调录屏 |
| DBS-FUSION-010 | 融合状态展示 | 显示 HRV → DBS 状态、最近发送时间、seq、ACK | 实时波形页或融合调试页可见发送状态 | 页面截图 |
| DBS-FUSION-011 | 安全降级提示 | HRV 中断或 DBS 超时后，提示降级为 LFP-only | 页面显示“HRV 无效，DBS 退回 LFP-only/等待固件确认” | 状态日志 |
| DBS-FUSION-012 | 日志归档 | 记录 score、seq、时间、ACK、失败原因 | 历史记录中能查看融合发送记录 | 历史记录截图 |

建议 App → DBS 压力分数包至少包含：

```text
version
flags
seq
timestamp 或 infer_count
score_raw
score_smoothed
quality
hrv_state
```

DBS 端融合建议使用：

```text
Ep(t) = score_smoothed / 100.0
```

# 5. 整体验收标准

## 5.1 最小可验收版本

满足以下条件，即可认为 App 与 DBS 连接的最小闭环链路跑通：

| 序号 | 验收项 | 标准 |
|---|---|---|
| 1 | DBS 连接 | App 能扫描、连接、断开和重连 DBS |
| 2 | GATT 识别 | App 能找到 DBS Write、Device Notify、Stream Data 特征 |
| 3 | 下行写入 | App 能向 DBS 发送至少一种测试命令，并收到 ACK |
| 4 | DBS 状态 | App 能显示 DBS 连接状态、电量或运行状态 |
| 5 | 压力分数发送 | App 能将 HRV 压力分数发送给 DBS |
| 6 | ACK 显示 | App 能显示“DBS 已接收”或错误原因 |
| 7 | 异常保护 | DBS 未连接、HRV 未校准、ACK 超时时 App 不崩溃且有提示 |
| 8 | 急停入口 | App 控制页有 E-STOP，命令可发送并有反馈 |

最小闭环链路应能完成：

```text
HRV pressure_score → App → DBS Write → DBS ACK → App 显示发送成功
```

---

## 5.2 完整可展示版本

满足以下条件，即可认为 App 与 DBS 连接模块达到比赛展示要求：

| 序号 | 验收项 | 标准 |
|---|---|---|
| 1 | 双设备同时在线 | HRV 胸环和 DBS 可同时连接，互不影响 |
| 2 | 实时波形 | CH1 显示 DBS-LFP，CH2 显示 ECG 和 R 峰 |
| 3 | HRV 指标 | 心率、RMSSD、pNN50、LF/HF 和压力分数正常显示 |
| 4 | 融合发送 | 压力分数可按 1 Hz 或约定频率发送给 DBS |
| 5 | DBS 反馈 | DBS ACK、运行状态和参数反馈可显示 |
| 6 | 刺激参数 | 可编辑并下发强度、频率、脉宽、模式 |
| 7 | 刺激启停 | 可开启/停止刺激，App 状态以 DBS 回传为准 |
| 8 | E-STOP | 急停可用，触发后有锁定/提示/记录 |
| 9 | 安全边界 | 超范围参数禁止发送；实际执行以 DBS 固件确认为准 |
| 10 | 历史记录 | 会话中保存 HRV、DBS 状态、参数和融合发送记录 |
| 11 | 联调日志 | 能展示最近发送时间、seq、score、ACK、错误原因 |
| 12 | 演示稳定性 | 连续运行 10–30 分钟无崩溃、明显卡顿或状态错乱 |

---

## 5.3 推荐联调顺序

建议按以下顺序推进，避免一次性改动过多：

1. 新建或完善独立 `DbsBleService`，不要破坏现有 HRV 胸环服务；
2. 完成 DBS 扫描、连接、断开、重连；
3. 完成 Service / Characteristic 发现；
4. 订阅 Device Notify，先解析 DBS 状态或 ACK；
5. 实现 Write 测试命令，确认 App → DBS 写入成功；
6. 实现压力分数发送包，打通 `HRV score → App → DBS`；
7. 加入 ACK、超时、失败提示和发送日志；
8. 订阅 Stream Data，解析 LFP 并绘制到 CH1；
9. 实现刺激参数下发和回读；
10. 实现刺激启停；
11. 实现 E-STOP；
12. 将 DBS 状态、参数和融合发送记录写入历史记录。
